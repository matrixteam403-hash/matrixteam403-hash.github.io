## درباره‌ی سایت

سایت با HTML، CSS و JavaScript ساده ساخته شده و برای اجرا به وابستگی یا فونت خارجی نیاز ندارد. فایل اصلی `index.html` است.

برای به‌روزرسانی متن‌ها یا اضافه‌کردن لینک‌ها، `index.html` را ویرایش کن. انتشار سایت از طریق GitHub Pages و شاخه‌ی `main` انجام می‌شود.
